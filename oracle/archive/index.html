      이 프로젝트에 대해
      
      
      리눅스 위에서 오라클 19c를 다루는 신입 DBA가 원리를 그림으로 먼저 익히고, DBA 실습에서 같은 내용을 직접 명령으로 해 보도록 만든 학습 사이트입니다. 장면마다 "이 내용 실습하기"로 해당 실습 레슨에 바로 갈 수 있습니다.

      참고 사항
      
      
      설명은 Oracle Database 19c 공식 문서 기준입니다. 서버 이름(dbserver02), 경로, FRA 한도(100G)는 DBA 실습의 가상 서버와 같은 값이고, 로그 시퀀스 번호, 시각, 태그는 설명을 위한 예시 값입니다. 콘솔 화면 가운데 NOARCHIVELOG일 때의 ARCHIVE LOG LIST, V$LOG 조회 결과의 모양, RMAN BACKUP 진행 줄은 공식 문서 예시로 확인하지 못한 형식이라 줄임표(…)로 줄였습니다. 온라인 리두 로그를 돌려 쓰는 방식은 Administrator's Guide의 아카이브 장에 있는 재사용 규칙으로 설명했고, 리두 로그 장은 따로 읽지 못했습니다. 컨트롤 파일 자동 백업의 기본값은 19c 문서 두 곳의 설명이 서로 다릅니다.
      
      
      근거 문서: Oracle Database 19c Administrator's Guide · 12 Managing Archived Redo Log Files (아카이브 로그 정의, NOARCHIVELOG와 ARCHIVELOG, 모드 바꾸는 순서, 보관 위치, 디스크가 찼을 때), Backup and Recovery User's Guide 19c · Configuring the RMAN Environment (빠른 복구 영역, 자동 백업 기본값, 보관 정책), Backup and Recovery User's Guide 19c · RMAN Backup Concepts (백업 세트, 백업 조각), Backup and Recovery User's Guide 19c · Backing Up the Database (PLUS ARCHIVELOG, 컨트롤 파일 자동 백업), Backup and Recovery User's Guide 19c · Performing Complete Database Recovery (RESTORE·RECOVER), Backup and Recovery User's Guide 19c · Maintaining RMAN Backups (RMAN 기록, OBSOLETE, FRA 가득 참), Oracle 튜토리얼 · Manage Backups (LIST BACKUP SUMMARY), Oracle Error Help · ORA-19809, Oracle Error Help · ORA-00257.
