      이 프로젝트에 대해
      
      
      리눅스 위에서 오라클 19c를 다루는 신입 DBA가 원리를 그림으로 먼저 익히고, DBA 실습에서 같은 내용을 직접 명령으로 해 보도록 만든 학습 사이트입니다. 장면마다 "이 내용 실습하기"로 해당 실습 레슨에 바로 갈 수 있습니다.
      
      
      만든 사람: 미스터오라클(김영조) · ambrokim@gmail.com · GitHub 저장소
      
    
      
    
      
      
      참고 사항
      
      
      설명은 Oracle Database 19c 공식 문서 기준입니다. 서버 이름(dbserver02), 리두 로그 그룹 세 개와 파일 이름은 DBA 실습의 가상 서버와 같은 값이고, 로그 크기, SCN, 시퀀스 번호, 대기 횟수와 시간, 초 단위 값은 설명을 위한 예시 값입니다. V$LOG, V$SYSTEM_EVENT, V$INSTANCE_RECOVERY 조회 결과의 열 모양은 공식 문서 예시로 확인하지 못한 형식입니다. alert log에 남는 "Checkpoint not complete" 문구는 이번에 읽은 문서에서 확인하지 못해 콘솔에 넣지 않았고, 같은 상황을 문서의 대기 이벤트 이름으로 설명했습니다. CKPT·DBWn 설명 일부는 Concepts 장의 뒷부분을 요약본으로 읽었습니다. "리두 로그 전환은 몇 분에 한 번이 적당하다" 같은 숫자 기준은 이번에 읽은 문서에서 찾지 못해 적지 않았습니다.
      
      
      근거 문서: Oracle Database 19c Concepts · Oracle Database Instance (체크포인트의 목적·종류·위치, 인스턴스 복구), Concepts 19c · Process Architecture (CKPT, DBWn, LGWR), Database Reference 19c · Descriptions of Wait Events (log file switch (checkpoint incomplete)), Database Performance Tuning Guide 19c · Instance Tuning Using Performance Views (리두 로그 수·크기, FAST_START_MTTR_TARGET), Database Reference 19c · V$INSTANCE_RECOVERY, Database Reference 19c · LOG_CHECKPOINT_TIMEOUT, Backup and Recovery User's Guide 19c · User-Managed Recovery: Advanced Scenarios (V$LOG 상태).
