      이 프로젝트에 대해
      
      
      리눅스 위에서 오라클 19c를 다루는 신입 DBA가 원리를 그림으로 먼저 익히고, DBA 실습에서 같은 내용을 직접 명령으로 해 보도록 만든 학습 사이트입니다. 장면마다 "이 내용 실습하기"로 해당 실습 레슨에 바로 갈 수 있습니다.
      
      
      만든 사람: 미스터오라클(김영조) · ambrokim@gmail.com · GitHub 저장소
      
    
      
    
      
      
      참고 사항
      
      
      설명은 Oracle Database 19c 공식 문서 기준입니다. 서버 이름(racnode1, racnode2), DB 이름(PAYDB), 인스턴스(PAYDB1, PAYDB2), 서비스(pay_oltp, pay_batch)와 preferred·available 설정, 03:10 재부팅과 07:40 복귀는 DBA 실습 11단계와 같은 값이고, 세션 수와 대기 횟수는 설명을 위한 예시 값입니다. -failback 옵션(19.3 이상)과 서비스가 available 인스턴스로 옮겨 가는 설명 일부는 RAC Administration Guide를 요약본으로 읽었습니다. 살아남은 인스턴스가 복구한다는 것은 Concepts에서 확인했지만, 그 인스턴스가 죽은 인스턴스의 redo를 읽는 세부 방식과 복구 단계별 진행은 이번에 원문으로 확인하지 못해 다루지 않았습니다. 화면의 crsctl·srvctl 출력은 줄을 줄였고, VIP가 옮겨 갔을 때 crsctl 자원 표의 상태 표기와 GV$SYSSTAT의 gc 통계 이름은 이번에 읽은 문서로 확인하지 못해 실제와 다를 수 있습니다.
      
      
      근거 문서: Real Application Clusters Administration and Deployment Guide 19c · Introduction to Oracle RAC (인스턴스·redo thread·Undo, Cache Fusion, GCS·GES·GRD, 인터커넥트, VIP, SCAN), RAC 19c · Glossary (LMON, LMS, Cache Fusion, GCS), RAC 19c · Workload Management with Dynamic Database Services (preferred·available, 자동으로 되돌아가지 않음, -failback), Database Reference 19c · Descriptions of Wait Events (gc cr request, gc current request, gc buffer busy acquire, gc cr block 2-way·3-way), Concepts 19c · Oracle Database Instance (redo thread, 살아남은 인스턴스의 인스턴스 복구).
