      이 프로젝트에 대해
      
      
      리눅스 위에서 오라클 19c를 다루는 신입 DBA가 원리를 그림으로 먼저 익히고, DBA 실습에서 같은 내용을 직접 명령으로 해 보도록 만든 학습 사이트입니다. 장면마다 "이 내용 실습하기"로 해당 실습 레슨에 바로 갈 수 있습니다.

      참고 사항
      
      
      설명은 Oracle Database 19c 공식 문서 기준입니다. 서버 이름(dbserver02)과 앱 계정(APP)은 DBA 실습과 같은 이름이고, DELIVERY_LOG 테이블과 인덱스 이름, 키 범위, 높이, 블록 수, 클러스터링 팩터, 행 수, 비용은 설명을 위한 예시 값입니다. 실행 계획 화면은 화면 폭 때문에 Bytes와 Time 열을 뺐습니다. Concepts의 "모든 키 열이 NULL인 행은 인덱스에 넣지 않는다"는 문장과 SQL Tuning Guide의 "인덱스에는 NULL 항목이 들어갈 수 없어 COUNT에 인덱스를 쓰지 못한다"는 설명은 원문으로 확인했습니다. 9장면의 복합 인덱스에 모든 행이 들어간다는 것은 이 규칙에서 바로 나오지만, 옵티마이저가 그 인덱스로 IS NULL 조건을 찾는다는 것과 9장면의 실행 계획은 문서에 적혀 있지 않습니다. 운영에 적용하기 전에 같은 데이터로 실행 계획을 꼭 확인하세요.
