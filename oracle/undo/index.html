      참고 사항
      
      
      설명은 Oracle Database 19c 공식 문서 기준입니다. 서버 이름(dbserver02), Undo 테이블스페이스 이름(UNDOTBS1)은 DBA 실습의 가상 서버와 같은 값이고, SCN, 시각, 초 단위 값, 행 값은 설명을 위한 예시 값입니다. ORA-01555 메시지의 롤백 세그먼트 번호와 이름, V$UNDOSTAT 조회 결과의 값은 예시이고 이름은 줄임표(…)로 줄였습니다. Undo 익스텐트 상태를 ACTIVE·UNEXPIRED·EXPIRED 세 이름으로 부르는 표는 이번에 읽은 문서에서 이름 목록으로는 확인하지 못했고, 문서의 unexpired·expired 설명과 "진행 중인 트랜잭션의 Undo는 덮어쓰지 않는다"는 튜토리얼 설명으로 그렸습니다. 고정 크기 Undo 테이블스페이스에서 UNDO_RETENTION이 무시되는지는 Administrator's Guide와 Database Reference(19.7 RU부터 달라짐)의 설명이 다릅니다.
      
      
      근거 문서: Oracle Database 19c Concepts · Data Concurrency and Consistency (문장 단위 읽기 일관성, CR 사본, 격리 수준), Administrator's Guide 19c · Managing Undo (Undo의 쓰임, 보존 기간 자동 조정, RETENTION GUARANTEE, V$UNDOSTAT, UNDOTBS1), Database Reference 19c · UNDO_RETENTION (기본값 900, 하한값), Oracle Error Help · ORA-01555, Oracle 튜토리얼 · Manage Undo Data.
