      이 프로젝트에 대해
      
      
      리눅스 위에서 오라클 19c를 다루는 신입 DBA가 원리를 그림으로 먼저 익히고, DBA 실습에서 같은 내용을 직접 명령으로 해 보도록 만든 학습 사이트입니다. 장면마다 "이 내용 실습하기"로 해당 실습 레슨에 바로 갈 수 있습니다.

      참고 사항
      
      
      설명은 Oracle Database 19c 공식 문서 기준입니다. 서버 이름(dbserver02), SGA_TARGET 8G, HugePages 4096개와 sysctl 파일 이름, STARTUP 화면의 크기 값은 리눅스 실습·DBA 실습의 가상 서버와 같은 값이고, 12G로 늘리는 작업과 PID·시각은 설명을 위한 예시 값입니다. 리눅스에서 백그라운드 프로세스 이름이 ora_이름_SID 형식이라는 것은 이번에 읽은 문서에서 직접 확인하지 못했고 실습 화면과 같게 두었습니다. HugePages가 모자랄 때 alert log에 나오는 문구와 오류 번호는 문서에 적혀 있지 않아 줄임표(…)로 줄였습니다. 공유 풀의 하위 구성 요소와 PGA_AGGREGATE_LIMIT 설명 일부는 문서의 뒷부분을 요약본으로 읽었고, PGA_AGGREGATE_LIMIT의 기본값 계산식은 확인하지 못해 적지 않았습니다. USE_LARGE_PAGES의 값 가운데 ONLY와 AUTO_ONLY만 이번에 읽은 문서로 확인했습니다.
