      이 프로젝트에 대해
      
      
      리눅스 위에서 오라클 19c를 다루는 신입 DBA가 원리를 그림으로 먼저 익히고, DBA 실습에서 같은 내용을 직접 명령으로 해 보도록 만든 학습 사이트입니다. 장면마다 "이 내용 실습하기"로 해당 실습 레슨에 바로 갈 수 있습니다.

      참고 사항
      
      
      설명은 Oracle Database 19c 공식 문서 기준입니다. 서버 이름(dbserver02)과 앱 계정(APP)은 DBA 실습과 같은 이름이고, DELIVERY_LOG 테이블과 IX_DLOG_CUST 인덱스, 이관 상황, 행 수·블록 수·비용·시간 같은 숫자는 설명을 위한 예시 값입니다. 실행 계획 화면은 문서의 열 머리글(Id, Operation, Name, Rows, Bytes, Cost (%CPU), Time)을 따랐지만 화면 폭 때문에 Bytes와 Time 열을 뺐습니다. 이 예에서 옵티마이저가 전체 스캔을 고른 이유는 SQL Tuning Guide의 "전체 스캔을 고르는 이유" 표 가운데 "작은 테이블" 항목으로 설명했고, 실제 비용 계산식은 문서에 공개되어 있지 않습니다. 통계를 새로 모은 뒤 이미 공유 풀에 있는 커서가 언제 다시 하드 파스되는지(무효화 시점)는 이번에 확인하지 못해 "다음 하드 파스 때"로만 적었습니다. 동적 통계의 기본 수준과 자동 통계 수집에 관한 설명 일부는 문서를 요약본으로 읽었습니다.
      
      
      근거 문서: SQL Tuning Guide 19c · Query Optimizer Concepts (변환기·추정기·계획 생성기, 선택도·카디널리티·비용, 적응형 계획), SQL Tuning Guide 19c · Optimizer Statistics Concepts (통계 종류, 동적 통계, 자동 통계 수집), SQL Tuning Guide 19c · Optimizer Access Paths (전체 스캔을 고르는 이유, 인덱스 범위 스캔), SQL Tuning Guide 19c · Generating and Displaying Execution Plans (DISPLAY_CURSOR, EXPLAIN PLAN과의 차이), SQL Tuning Guide 19c · SQL Processing (하드 파스와 최적화).
