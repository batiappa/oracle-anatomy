      이 프로젝트에 대해
      
      
      리눅스 위에서 오라클 19c를 다루는 신입 DBA가 원리를 그림으로 먼저 익히고, DBA 실습에서 같은 내용을 직접 명령으로 해 보도록 만든 학습 사이트입니다. 장면마다 "이 내용 실습하기"로 해당 실습 레슨에 바로 갈 수 있습니다.
      
      
      만든 사람: 미스터오라클(김영조) · ambrokim@gmail.com · GitHub 저장소
      
    
      
    
      
      
      참고 사항
      
      
      설명은 Oracle Database 19c 공식 문서 기준입니다. 서버 이름(dbserver02), 계정(APP, APP_BATCH), 세션 번호 142는 DBA 실습 3단계 "락을 잡고 있는 세션 정리하기"와 같은 값이고, 테이블 이름, 행 값, 시각, 초 단위 값은 설명을 위한 예시 값입니다. V$SESSION 조회 결과의 열 모양은 공식 문서 예시로 확인하지 못한 형식입니다. 행 잠금 정보가 블록 안에만 있고 잠금을 키우지 않는다는 설명, 교착 상태 때 문장 하나만 롤백된다는 설명은 Concepts 장의 뒷부분을 요약본으로만 읽었습니다. DDL이 DML 잠금에 막혔을 때 나오는 오류 번호와 enq: TX - row lock contention의 대기 클래스는 이번에 읽은 문서에서 확인하지 못해 적지 않았습니다.
      
      
      근거 문서: Oracle Database 19c Concepts · Data Concurrency and Consistency (행 잠금 TX, 테이블 잠금 TM, ITL, 읽기와 쓰기, 교착 상태, 잠금 기간), Database Reference 19c · Descriptions of Wait Events (enq: TX - row lock contention), Database Reference 19c · Oracle Enqueue Names (TX, TM), Database Performance Tuning Guide 19c · Instance Tuning Using Performance Views (V$SESSION의 막는 세션, V$LOCK).
