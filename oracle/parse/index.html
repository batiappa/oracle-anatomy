      참고 사항
      
      
      설명은 Oracle Database 19c 공식 문서 기준입니다. 서버 이름(dbserver02)과 ORDER_HIST 테이블은 DBA 실습과 같은 이름이고, 배포 상황, CPU 사용률, SQL_ID, 실행 횟수, 파스 횟수 같은 숫자는 설명을 위한 예시 값입니다. V$SQL·V$SYSSTAT 화면은 문서의 열과 통계 이름을 따랐지만 줄 배치는 실제와 다를 수 있습니다. CURSOR_SHARING=FORCE로 바뀐 SQL의 시스템 바인드 이름(SYS_B_0)은 문서의 예를 따랐고, 이 설정이 파스 횟수를 줄이지 않는다는 설명은 문서 뒷부분을 요약본으로 읽어 확인했습니다. 같은 모양의 SQL을 묶어 세는 FORCE_MATCHING_SIGNATURE 열과 ORA-04031, SESSION_CACHED_CURSORS는 이번에 읽은 문서로 확인하지 못해 다루지 않았습니다.
