      이 프로젝트에 대해
      
      
      리눅스 위에서 오라클 19c를 다루는 신입 DBA가 원리를 그림으로 먼저 익히고, DBA 실습에서 같은 내용을 직접 명령으로 해 보도록 만든 학습 사이트입니다. 장면마다 "이 내용 실습하기"로 해당 실습 레슨에 바로 갈 수 있습니다.

      참고 사항
      
      
      설명은 Oracle Database 19c 공식 문서 기준입니다. 서버 이름(dbserver02), SID(ORCL), 파일 경로, SGA 크기는 DBA 실습의 가상 서버와 같은 값이고, 출력의 바이트 수와 시각은 설명을 위한 예시 값입니다. SMON이 인스턴스 복구를 맡는다는 문장은 Concepts 문서에서 끝까지 읽어 확인하지 못했습니다.
