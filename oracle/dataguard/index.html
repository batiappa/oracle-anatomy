      이 프로젝트에 대해
      
      
      리눅스 위에서 오라클 19c를 다루는 신입 DBA가 원리를 그림으로 먼저 익히고, DBA 실습에서 같은 내용을 직접 명령으로 해 보도록 만든 학습 사이트입니다. 장면마다 "이 내용 실습하기"로 해당 실습 레슨에 바로 갈 수 있습니다.

      참고 사항
      
      
      설명은 Oracle Database 19c 공식 문서 기준입니다. 서버 이름(dbserver02, dbserver03), DB 이름(orcl, orclstby), 구성 이름(orcl_dg), 최대 성능 모드는 DBA 실습 10단계와 같은 값이고, 장애 상황, 시각, 지연 값, 로그 번호는 설명을 위한 예시 값입니다. DGMGRL의 FAILOVER가 성공했을 때 나오는 메시지는 이번에 읽은 문서에서 찾지 못해 줄임표(…)로 줄였습니다. SHOW CONFIGURATION·VALIDATE DATABASE·V$DATAGUARD_PROCESS 화면은 줄을 줄였고, V$STANDBY_LOG의 상태 값은 실제와 다를 수 있습니다. 대기 DB에서 redo를 받아 쓰고 적용하는 세부 프로세스(PRnn 등)와 ASYNC 전송 프로세스 이름은 다루지 않았습니다.
      
      
      근거 문서: Data Guard Concepts and Administration 19c · Introduction (물리 대기 DB, 보호 모드, 스위치오버·페일오버), Redo Transport Services (SYNC·ASYNC, 대기 리두 로그, RFS), Redo Apply Services (MRP, 실시간 적용), Data Guard Protection Modes, Role Transitions (페일오버의 데이터 손실, 옛 주 DB 되살리기), Data Guard Broker 19c · Switchover and Failover Operations (FAILOVER, IMMEDIATE, REINSTATE DATABASE, ORA-16661, fast-start failover), Data Guard Broker 19c · Managing Configuration Members (APPLY-ON·OFF, TRANSPORT-ON·OFF).
