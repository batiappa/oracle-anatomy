이 터미널은 진짜 리눅스와 오라클이 아니라 브라우저 안의 흉내입니다. 보라색 ⓘ 줄은 실습 안내이고, 실제 서버에는 나오지 않습니다. ↑↓ 이전 명령, Tab 자동 완성.

이 실습은 1·2단계 리눅스 실습실에서 이어집니다. 2단계에서 준비한 dbserver02에 Oracle Database 19c(설치 버전 19.3)를 설치하고 ORCL 데이터베이스를 만든 상황입니다. 명령과 절차는 Oracle Database 19c 공식 문서(Administrator's Guide, SQL Language Reference, SQL*Plus User's Guide, Net Services Reference, Backup and Recovery User's Guide, Database Reference, Error Messages)를 기준으로 삼았고, 레슨마다 근거 문서를 붙였습니다.

공식 문서 예시로 확인한 출력: SQL*Plus 시작 화면의 형식(문서 예시는 19.1), "Connected to an idle instance."와 "ORACLE instance started." 및 SGA 줄 이름, lsnrctl status·start·stop·services의 형식, rman 접속 문구, SHOW ALL과 CROSSCHECK의 형식, ARCHIVE LOG LIST(아카이브 모드)의 형식, KILL 뒤의 KILLED·PSEUDO 표시, 레슨에 인용한 ORA- 오류 문구. 확인하지 못한 출력: "Database mounted/opened/closed/dismounted", "ORACLE instance shut down", DDL 뒤의 "User created." 같은 피드백 문구, SHOW PARAMETER의 열 모양, NOARCHIVELOG일 때의 ARCHIVE LOG LIST, RMAN BACKUP 진행 줄과 LIST BACKUP SUMMARY·REPORT의 표, 리스너가 없을 때 lsnrctl의 TNS 오류 줄, orapwd의 암호 질문 문구, 레슨에 인용하지 않은 일부 ORA-·SP2- 오류 문구. 이런 출력은 실제 19c에서 보이는 형식을 따르려 했지만 공식 문서로는 확인하지 못했고, 화면에 ⓘ 줄로 함께 알려 줍니다.

SQL 엔진은 실습에 필요한 SELECT(조인, WHERE, GROUP BY, ORDER BY, 집계 함수)와 몇 가지 DDL만 흉내 냅니다. 숫자, 날짜, SID, PID, DBID, 백업 파일 이름과 업무 테이블의 행은 설명용 예시입니다.
