      About this project
      
      
      A learning site for new DBAs working with Oracle 19c on Linux: learn the principles from pictures first, then try the same things yourself as commands in the Linux Lab. From each scene, "Practice this" takes you straight to the matching lab lesson.
      
      
      Created by: Kim Youngjo · ambrokim@gmail.com · GitHub repository
      
    
      
    
      
      
      Notes
      
      
      Explanations are based on Oracle Linux 8 and the Oracle Database 19c installation guide. The server name (dbserver01), paths, UIDs, and memory sizes are the same values as the virtual server in the Linux Lab, and figures such as PIDs and /u01 usage are example values for illustration.
      
      
      Reference documents: hier(7) · Linux directory hierarchy, passwd(5) · /etc/passwd format, Bash manual · Command Search and Execution (PATH, 127), umask(2), fork(2), execve(2), shmget(2) · System V shared memory, SHMMAX and SHMALL, proc_meminfo(5), sysctl(8), Linux kernel documentation · HugeTLB Pages, Oracle 19c Installation Guide · OFA path examples, Oracle 19c Installation Guide · Configuring user environments (startup files, umask 022), Oracle 19c Administrator's Guide · Chapter 1 (OS authentication, OSDBA group), Oracle 19c Installation Guide · Server Configuration Checklist (swap guideline), Oracle Grid Infrastructure 19c Installation Guide · Minimum Parameter Settings (kernel parameters), Oracle Grid Infrastructure 19c Installation Guide · Checking Resource Limits (limits), Oracle 19c Administrator's Reference for Linux and UNIX · Appendix A (HugePages, not usable with AMM), Oracle 19c Installation Guide · THP on UEK Kernels, Oracle Grid Infrastructure 19c Installation Guide · Disk I/O Scheduler on Linux 8, Oracle Error Help · ORA-00257.
