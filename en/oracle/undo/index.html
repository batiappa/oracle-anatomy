      About this project
      
      
      A learning site for new DBAs who run Oracle 19c on Linux: first see the principles as pictures, then do the same things yourself with commands in the DBA labs. Each scene has a "Practice this" link that takes you straight to the matching lab lesson.
      
      
      Created by: Mr.Oracle (Kim Youngjo) · ambrokim@gmail.com · GitHub repository
      
    
      
    
      
      
      Notes
      
      
      The explanations follow the official Oracle Database 19c documentation. The server name (dbserver02) and undo tablespace name (UNDOTBS1) match the virtual server in the DBA labs; SCNs, times, second counts and row values are example values. The rollback segment number and name in the ORA-01555 message and the values in the V$UNDOSTAT result are examples, and the name is shortened with an ellipsis (…). A list naming undo extent states ACTIVE, UNEXPIRED and EXPIRED was not found in the pages read; the drawing follows the documentation's description of unexpired and expired undo and the tutorial's statement that undo of an active transaction is never overwritten. Whether UNDO_RETENTION is ignored for a fixed-size undo tablespace differs between the Administrator's Guide and the Database Reference (changed from Release Update 19.7).
      
      
      Sources: Oracle Database 19c Concepts · Data Concurrency and Consistency (statement-level read consistency, CR copies, isolation levels), Administrator's Guide 19c · Managing Undo (uses of undo, automatic retention tuning, RETENTION GUARANTEE, V$UNDOSTAT, UNDOTBS1), Database Reference 19c · UNDO_RETENTION (default 900, low threshold), Oracle Error Help · ORA-01555, Oracle tutorial · Manage Undo Data.
