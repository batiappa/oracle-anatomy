      About this project
      
      
      A learning site for new DBAs who run Oracle 19c on Linux: first see the principles as pictures, then do the same things yourself with commands in the DBA labs. Each scene has a "Practice this" link that takes you straight to the matching lab lesson.
      
      
      Created by: Mr.Oracle (Kim Youngjo) · ambrokim@gmail.com · GitHub repository
      
    
      
    
      
      
      Notes
      
      
      The explanations follow the official Oracle Database 19c documentation. The server name (dbserver02) and the ORDER_HIST table match the DBA labs; the release scenario, CPU usage, SQL_IDs, execution counts, parse counts and other numbers are example values. The V$SQL and V$SYSSTAT screens use the column and statistic names in the documentation, but their layout may differ from the real output. The system bind name (SYS_B_0) in SQL rewritten by CURSOR_SHARING=FORCE follows the documentation example, and the statement that this setting does not reduce the parse count was confirmed from a summary of the later part of the page. The FORCE_MATCHING_SIGNATURE column for grouping statements of the same shape, ORA-04031 and SESSION_CACHED_CURSORS were not confirmed in the pages read, so they are not covered.
      
      
      Sources: SQL Tuning Guide 19c · SQL Processing (parse stages, hard and soft parses, SQL ID), SQL Tuning Guide 19c · Improving Real-World Performance Through Cursor Sharing (identical SQL, parent and child cursors, bind variables, CURSOR_SHARING, bind peeking), Database Performance Tuning Guide 19c · Tuning the Shared Pool and the Large Pool (library cache, data dictionary cache, literal SQL), Concepts 19c · Memory Architecture (private SQL area, cursors), Database Reference 19c · Descriptions of Wait Events (library cache: mutex X).
