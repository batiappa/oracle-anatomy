      About this project
      
      
      A learning site for new DBAs who run Oracle 19c on Linux: first see the principles as pictures, then do the same things yourself with commands in the DBA labs. Each scene has a "Practice this" link that takes you straight to the matching lab lesson.
      
      
      Created by: Mr.Oracle (Kim Youngjo) · ambrokim@gmail.com · GitHub repository
      
    
      
    
      
      
      Notes
      
      
      The explanations follow the official Oracle Database 19c documentation. The server name (dbserver02), SID (ORCL), file paths and SGA size match the virtual server in the DBA labs; byte counts and times in the output are example values. The statement that SMON performs instance recovery could not be read in full in the Concepts guide.
      
      
      Sources: Oracle Database 19c Concepts · 14 Oracle Database Instance (definitions of instance and database, startup and shutdown stages, instance recovery), Oracle Database 19c Administrator's Guide · 3 Starting Up and Shutting Down (parameter file search order, NOMOUNT·MOUNT·OPEN, SHUTDOWN modes), SQL*Plus 19c User's Guide and Reference · STARTUP, Oracle tutorial · Start up and Shut down the Oracle Database Instance (STARTUP·SHUTDOWN output), Oracle 19c Reference · V$INSTANCE, Oracle 19c Reference · V$DATABASE, Oracle 19c Administrator's Guide · Managing Control Files, Oracle Error Help · ORA-00205, Oracle Error Help · ORA-01157, Oracle 19c Error Messages (ORA-01219), Oracle 19c Error Messages (ORA-01507).
