      About this project
      
      
      A learning site for new DBAs who run Oracle 19c on Linux: first see the principles as pictures, then do the same things yourself with commands in the DBA labs. Each scene has a "Practice this" link that takes you straight to the matching lab lesson.
      
      
      Created by: Mr.Oracle (Kim Youngjo) · ambrokim@gmail.com · GitHub repository
      
    
      
    
      
      
      Notes
      
      
      The explanations follow the official Oracle Database 19c documentation. The server name (dbserver02), paths and FRA limit (100G) match the virtual server in the DBA labs; log sequence numbers, times and tags are example values. Among the console output, ARCHIVE LOG LIST in NOARCHIVELOG mode, the shape of the V$LOG query result, and the RMAN BACKUP progress lines could not be confirmed against documentation examples, so the progress lines are shortened with an ellipsis (…). The way online redo logs are reused is explained from the reuse rules in the archiving chapter of the Administrator's Guide; the redo log chapter itself was not read. Two places in the 19c documentation disagree about the default for control file autobackup.
      
      
      Sources: Oracle Database 19c Administrator's Guide · 12 Managing Archived Redo Log Files (archived log definition, NOARCHIVELOG and ARCHIVELOG, switching modes, destinations, full disk), Backup and Recovery User's Guide 19c · Configuring the RMAN Environment (fast recovery area, autobackup default, retention policy), Backup and Recovery User's Guide 19c · RMAN Backup Concepts (backup sets, backup pieces), Backup and Recovery User's Guide 19c · Backing Up the Database (PLUS ARCHIVELOG, control file autobackup), Backup and Recovery User's Guide 19c · Performing Complete Database Recovery (RESTORE·RECOVER), Backup and Recovery User's Guide 19c · Maintaining RMAN Backups (RMAN repository, OBSOLETE, full FRA), Oracle tutorial · Manage Backups (LIST BACKUP SUMMARY), Oracle Error Help · ORA-19809, Oracle Error Help · ORA-00257.
