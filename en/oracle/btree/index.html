      About this project
      
      
      A learning site for new DBAs who run Oracle 19c on Linux: first see the principles as pictures, then do the same things yourself with commands in the DBA labs. Each scene has a "Practice this" link that takes you straight to the matching lab lesson.
      
      
      Created by: Mr.Oracle (Kim Youngjo) · ambrokim@gmail.com · GitHub repository
      
    
      
    
      
      
      Notes
      
      
      The explanations follow the official Oracle Database 19c documentation. The server name (dbserver02) and the app account (APP) match the DBA labs; the DELIVERY_LOG table, index names, key ranges, heights, block counts, clustering factors, row counts and costs are example values. The Bytes and Time columns are dropped from the plan screens to fit. That a single-column B-tree index does not store NULLs, and that rows whose indexed columns are all NULL are not indexed, was confirmed in the documentation. The fix in scene 9 (a composite index with a NOT NULL column appended, so that every row is indexed) is derived from that statement; the documentation does not describe this fix as such. Always check the execution plan with the same data before applying it in production.
      
      
      Sources: Oracle Database 19c Concepts · Indexes and Index-Organized Tables (B-tree structure, height, leaf links, unique and range scans, clustering factor, NULLs, composite indexes, index maintenance), SQL Tuning Guide 19c · Optimizer Access Paths (rowids, index unique and range scans, reasons for full scans).
