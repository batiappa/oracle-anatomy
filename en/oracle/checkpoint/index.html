      About this project
      
      
      A learning site for new DBAs who run Oracle 19c on Linux: first see the principles as pictures, then do the same things yourself with commands in the DBA labs. Each scene has a "Practice this" link that takes you straight to the matching lab lesson.
      
      
      Created by: Mr.Oracle (Kim Youngjo) · ambrokim@gmail.com · GitHub repository
      
    
      
    
      
      
      Notes
      
      
      The explanations follow the official Oracle Database 19c documentation. The server name (dbserver02), the three redo log groups and their file names match the virtual server in the DBA labs; log sizes, SCNs, sequence numbers, wait counts and times, and second counts are example values. The column layout of the V$LOG, V$SYSTEM_EVENT and V$INSTANCE_RECOVERY query results could not be confirmed against documentation examples. The "Checkpoint not complete" alert log wording was not found in the pages read, so it is not shown in the console; the same situation is explained with the wait event name from the documentation. Some of the CKPT and DBWn details come from a summary of the later part of the Concepts chapters. A numeric rule such as "a log switch every so many minutes" was not found in the pages read, so none is given.
      
      
      Sources: Oracle Database 19c Concepts · Oracle Database Instance (purpose, types and position of checkpoints, instance recovery), Concepts 19c · Process Architecture (CKPT, DBWn, LGWR), Database Reference 19c · Descriptions of Wait Events (log file switch (checkpoint incomplete)), Database Performance Tuning Guide 19c · Instance Tuning Using Performance Views (number and size of redo logs, FAST_START_MTTR_TARGET), Database Reference 19c · V$INSTANCE_RECOVERY, Database Reference 19c · LOG_CHECKPOINT_TIMEOUT, Backup and Recovery User's Guide 19c · User-Managed Recovery: Advanced Scenarios (V$LOG status).
